# ESCOPO TÉCNICO: Site de Aniversário Colaborativo (18 anos do Rian)

## 1. Visão Geral do Projeto
- **Objetivo:** Criar um site interativo, dinâmico e focado em humor/memes para comemorar o aniversário de 18 anos do Rian Baccarin (ocorrido em 17/06).
- **Público-alvo:** Amigos e familiares jovens.
- **Temática Visual:** "Memes, Zoeira, Cultura de Internet (Shitpost organizado) e Baile Funk".
- **Funcionalidade Principal:** Um mural colaborativo em tempo real onde os usuários possam postar fotos e mensagens de felicitação, além de uma área com quiz e playlist colaborativa.

## 2. Stack Tecnológica Sugerida (Ajuste conforme preferência)
- **Frontend:** React.js ou HTML5 puro com Tailwind CSS (para estilização rápida e responsiva).
- **Animações:** Canvas-confetti (biblioteca JS) e Framer Motion (se usar React) ou CSS Animations.
- **Banco de Dados (Persistência):** Supabase ou Firebase (Plano Gratuito) para salvar as mensagens e imagens enviadas pelos amigos em tempo real.

## 3. Identidade Visual e Estética (A Zoeira)
- **Cores:** Cores vibrantes e contrastantes (ex: Preto de fundo com detalhes em Verde Neon, Rosa Choque ou Roxo).
- **Fontes:** Mistura de fontes de memes (Impact ou Comic Sans para piadas) com uma fonte moderna (Inter ou Montserrat) para leitura.
- **Elementos Visuais:** Adesivos (stickers) de memes clássicos espalhados pelo fundo da tela (Cachorro caramelo, Flork, Memes do WhatsApp).
- **Cursor Customizado:** Substituir o ponteiro do mouse por um ícone pequeno de "Óculos de Juliet" ou um recorte da cara do Rian.

## 4. Estrutura de Páginas e Funcionalidades

### 4.1. Seção 1: Hero / Tela de Boas-Vindas
- **Título de Destaque:** "O RIAN FEZ 18! 🔞 (O cria finalmente é maior de idade)"
- **Banner:** Uma foto engraçada do Rian recortada no centro.
- **Contador de Tempo:** Exibir um contador dinâmico com o tempo de vida do Rian (Ex: "O Rian já sobreviveu a X dias, Y horas e Z segundos").
- **Efeito de Entrada:** Chuva de confetes automática ao carregar a página utilizando a biblioteca `canvas-confetti`.

### 4.2. Seção 2: O Mural de Memórias (Colaborativo)
- **Exibição:** Um grid estilo Pinterest (Masonry layout) com cartões que parecem fotos Polaroid ou blocos de notas zoados.
- **Conteúdo do Card:** Foto enviada, Mensagem textualmente editada, Nome do autor e botões de reação (Ex: ❤️, 😂, 🚀).
- **Interatividade:** Ao clicar em um card, ele deve abrir em um modal expandido com zoom na foto e a mensagem completa.
- **Formulário de Envio (Aba ou Modal):**
  - Campo: Nome do Amigo (Obrigatório).
  - Campo: Mensagem/Zoeira (Obrigatório).
  - Campo: Upload de Foto (Opcional - integrar com o storage do Supabase/Firebase).
  - Mensagem de sucesso ao enviar: Exibir um alerta personalizado: "Tamo junto! O Rian vai ver essa vergonha em breve. 😂".

### 4.3. Seção 3: O Baile Funk do Rian (Áudio & Música)
- **Player de Música:** Inserir um widget do Spotify Embed configurado para tocar uma playlist específica.
- **Botão Playlist Colaborativa:** Um botão grande em destaque: `"🎵 ADICIONAR UM FUNK NO BAILE"`. Ao clicar, abre o link direto da playlist colaborativa do Spotify em uma nova aba para que os amigos adicionem músicas por lá.
- **Mesa de Efeitos (Soundboard):** 3 a 4 botões pequenos com áudios curtos de memes de funk (ex: "Eita", "Receba", ou vinhetas clássicas de funk). Ao clicar, o áudio toca na hora.

### 4.4. Seção 4: Quiz "O Quanto Você Conhece o Rian?"
- **Formato:** Um minijogo de 5 perguntas de múltipla escolha com respostas zoeiras.
- **Exemplo de Pergunta:** "Qual é o maior talento oculto do Rian?"
  - A) Dormir em qualquer lugar.
  - B) Gastar o dinheiro que não tem com besteira.
  - C) Dançar funk igual uma lagartixa.
- **Feedback:** Ao final, exibir uma pontuação com um meme baseado no resultado (Ex: 0-2 acertos: "Você é um estranho"; 3-5 acertos: "Você é o verdadeiro parça").

## 5. Instruções de Desenvolvimento para o Claude Code

Por favor, siga estes passos para criar o projeto:
1. Comece gerando a estrutura base do projeto usando HTML/Tailwind ou React (crie arquivos limpos e modulares).
2. Forneça o código para a interface visual e o design focado em memes (adicione classes do Tailwind para o visual dark/neon e responsivo para celulares).
3. Implemente a lógica do formulário e crie a simulação (mock) de envio de mensagens para o mural.
4. Adicione as animações (confete na entrada) e os efeitos sonoros dos botões de meme.
5. Deixe o código preparado com variáveis de ambiente fáceis de configurar para quando eu for conectar ao banco de dados (Supabase/Firebase) para salvar as fotos e mensagens definitivamente.
